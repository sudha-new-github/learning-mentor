## 🚀 Deploy to GitHub Pages

### One-time setup
You need Node.js installed. Check: `node -v`
If not installed → [nodejs.org](https://nodejs.org) (LTS version)

### Deploy (3 commands in Terminal)
```bash
cd path/to/learning-mentor
npm install
npm run deploy
```

Live at: `https://sudha-new-github.github.io/learning-mentor/`

### After first deploy
Go to GitHub repo → Settings → Pages → Source = `gh-pages` branch, `/ (root)`
